  identified hierarchy/state problems.
- A full Settings information-architecture redesign: deferred. Plan 010 fixes

  a later layout plan should be based on usage evidence rather than bundled
  into the assignment-page redesign.
- Public image/font delivery and route-level code splitting: valid performance
  follow-ups, but deferred from this UI-state plan set so the visual and
  interaction foundations land first.
- Security, backend authorization, database migrations, and dependency posture
  were outside this focused UI audit except where older Plans 002–004 already
  cover them.
